# T-003: Inventory All Agent Metadata

## Objective

Create one capability record per current custom agent, including file and inline configuration metadata, before any agent is converted or removed.

## Scope

- Inputs: `agents/*.agent.md`, inline `opencode.json` agent declarations, and current runtime discovery.
- Allowed outputs: this Task-Spec and the two T-003 evidence files.
- Forbidden: agent, configuration, runtime, or global-state changes.

## Required Fields

Each record must identify name, source, description, mode, model, temperature, steps, declared tools, Task/TODO permission, primary status, and whether it is one of the six dev-agent conversion targets.

## Verification

```bash
test -f .specs/changes/harness-skill-based-migration/evidence/t-003-agent-capability.csv
test -f .specs/changes/harness-skill-based-migration/evidence/t-003-agent-summary.md
git diff --check -- .specs/changes/harness-skill-based-migration
```

## Evidence and Rollback

- Evidence: capability CSV and summary.
- Rollback: remove only the T-003 Task-Spec and evidence files, then restore allocation/state to the prior task.

## Stop Conditions

- An agent cannot be uniquely identified from file, inline config, or runtime data.
- A record would require changing the active agent/configuration surface.
