# T-001: Snapshot Repository and Active Branch

## Objective

Capture a reproducible, sanitized baseline of the repository and active branch before any migration implementation surface changes.

## Inputs

| Input | Required use |
|---|---|
| T-000 package | Canonical evidence and task destination |
| Current Git repository | Branch, commit, status, log, and diff summary |
| Current migration-sensitive surfaces | Inventory and checksum scope |
| Roadmap V2 and Backlog V2 | T-001 acceptance, evidence, and rollback contract |

## Allowed Paths

- `.specs/changes/harness-skill-based-migration/state.md`
- `.specs/changes/harness-skill-based-migration/allocation.yaml`
- `.specs/changes/harness-skill-based-migration/tasks/T-001.md`
- `.specs/changes/harness-skill-based-migration/evidence/baseline.md`
- `.specs/changes/harness-skill-based-migration/evidence/checksums.sha256`

## Forbidden Paths

- `.specs/memory/active-state.md`
- `AGENTS.md`, `opencode.json`, `opencode.jsonc`
- `agents/`, `commands/`, `skills/`, `plugins/`, `tools/`, `test/`, `.specs/archive/`, and `.git/`
- Any `.env` or `.env.*` file

## Required Rules and Tools

- Required rules: Roadmap V2 Definition of Ready and invariants, allocation contract, source authority hierarchy.
- Required skills: `task-spec`, `customize-opencode`.
- Allowed tools: RTK-wrapped Git commands, Git, Node, Read, Glob, Grep, Bash, Apply Patch, TODOWRITE.
- Allowed MCPs: none.
- Execution profile: primary parent session; no delegation.

## Deliverables

| Deliverable | Evidence |
|---|---|
| Baseline report | `evidence/baseline.md` records repository root, branch, commit, Git status, log, diff summary, and inventory counts |
| Checksum manifest | `evidence/checksums.sha256` checks every current migration-sensitive non-secret file |
| Local task state | `state.md`, `allocation.yaml`, and this Task-Spec record the bounded task |

## Acceptance Criteria

- [x] Git branch, commit, dirty state, log, and diff summary are recorded.
- [x] The inventory covers AGENTS, OpenCode config, agents, skills, commands, plugins, tools, docs, `.specs/shared`, and tests.
- [x] Every present migration-sensitive non-secret file has a checksum.
- [x] Missing historical surfaces are explicitly recorded, not silently omitted.
- [x] The baseline report contains no credential, token, or secret value.
- [x] No file outside Allowed Paths changes.

## Verification

```bash
test -f .specs/changes/harness-skill-based-migration/evidence/baseline.md
test -f .specs/changes/harness-skill-based-migration/evidence/checksums.sha256
sha256sum -c .specs/changes/harness-skill-based-migration/evidence/checksums.sha256
git diff --check -- .specs/changes/harness-skill-based-migration .specs/memory/harness-skill-based-migration
```

## Evidence and Rollback

- Evidence: Git state, inventory report, checksum manifest, and scoped Task-Spec.
- Rollback: remove only `baseline.md`, `checksums.sha256`, and `tasks/T-001.md`; restore the prior T-000 state/allocation content.

## Stop Conditions

- The snapshot requires a path outside the defined inventory surfaces.
- A source path is unavailable and cannot be marked missing without changing the baseline definition.
- A candidate file is `.env` or `.env.*`, or evidence would expose a secret value.
- The task requires changes to global state or runtime configuration.
