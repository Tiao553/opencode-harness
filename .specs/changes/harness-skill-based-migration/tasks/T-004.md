# T-004: Behavior Ownership Inventory

## Objective

Map the current behavior ownership of commands, skills, shared contracts, and plugins; classify enforcement strength; and record unresolved references without changing runtime surfaces.

## Scope and Verification

- Inputs: `commands/`, `skills/`, `.specs/shared/`, `sdd/architecture/`, `plugins/`, and `tools/`.
- Allowed outputs: this Task-Spec and `evidence/t-004-behavior-ownership.md`.
- Forbidden: changes to all inspected runtime surfaces and global state.
- Verify the report contains every command, skill, configured plugin, enforcement classification, and missing-reference record.

## Evidence and Rollback

- Evidence: behavior ownership report.
- Rollback: remove only this Task-Spec and report, then restore allocation/state to T-003.

## Stop Conditions

- A target behavior has no source and no explicit unresolved decision.
- A plugin is claimed as a hard gate without deterministic evidence.
