# Structure

## Surfaces

| Surface | Role |
| --- | --- |
| `.specs/templates/prd-template.md` | product/problem contract |
| `.specs/templates/adr-template.md` | architecture decision contract |
| `.specs/templates/test-spec-template.md` | validation and regression contract |
| `.specs/templates/validation-report-template.md` | evidence verdict contract |
| `.specs/templates/ship-summary-template.md` | closure contract |
| `.specs/shared/allocation-contract.md` | allocation authority |
| `.specs/shared/global-allocation-contract.md` | wave/phase boundary |
| `.specs/shared/local-allocation-contract.md` | task/todo boundary |
| `docs/HARNESS_V3_ARTIFACT_TEMPLATE_CATALOG.md` | shareable template map |

## Risk

Template hardening can create cumbersome artifacts if it over-specifies every small task. The templates must define required fields while still allowing irrelevant sections to be marked not applicable.
