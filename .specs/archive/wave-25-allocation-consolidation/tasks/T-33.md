# T-33: Edge Case Test Execution

**Task ID:** T-33  
**Phase:** 4 (Testing, Validation & Ship)  
**Status:** READY FOR EXECUTION (after T-32)  
**Owner:** altitude-execution  
**Duration:** 4 hours  
**Depends:** T-31 (integration baseline), T-32 (load baseline)

## Objective

Execute 18 edge case tests covering critical, high-risk, and medium-risk allocation scenarios. Verify resilience and correct error handling.

## Test Categories (18 Total)

**CRITICAL Edge Cases (6 Tests, must not break)**
- E-01: Circular specialist delegation (A→B→C→A)
- E-02: Scope violation re-violation
- E-03: File matches both allowed AND forbidden (forbidden wins)
- E-04: Specialist without grounding bundle
- E-05: Specialist output violates scope
- E-06: Scope narrowing breaks dependent tasks

**HIGH-Risk Edge Cases (8 Tests, ≥ 7/8 must PASS)**
- E-07: Nested specialist delegation (depth > 3)
- E-08: Concurrent writes to same file
- E-09: Cross-user approval conflicts
- E-10: Pattern matching ambiguity (glob vs regex)
- E-11: Ledger event reordering
- E-12: Todo without verify clause
- E-13: Specialist invoked mid-task
- E-14: Task narrows but parent already narrow

**MEDIUM-Risk Edge Cases (4 Tests, ≥ 3/4 must PASS)**
- E-15: Ledger corruption (missing events)
- E-16: Rollback when specialist output violates
- E-17: Cross-wave allocation conflicts
- E-18: Empty allowed_files (default deny)
