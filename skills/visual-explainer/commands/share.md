# Share Command

## Process

1. Read the material to be shared and identify the target audience.
2. Remove unnecessary implementation detail that does not help that audience.
3. Preserve the critical facts, findings, decisions, and next steps.
4. Package the result into a single artifact that can stand alone.

## Output

- One shareable artifact optimized for review by someone outside the immediate chat.
