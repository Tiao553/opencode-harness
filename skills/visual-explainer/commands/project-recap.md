# Project Recap Command

## Process

1. Read the project context, status inputs, and any referenced artifacts.
2. Summarize the current state, key changes, open risks, and recommended next moves.
3. Organize the recap visually so a reviewer can scan it quickly.

## Output

- A standalone recap artifact for project review or asynchronous sharing.
