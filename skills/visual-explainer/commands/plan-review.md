# Plan Review Command

## Process

1. Read the plan and any supporting context.
2. Identify sequencing, dependencies, missing steps, and execution risks.
3. Present the plan structure visually so weak spots are obvious.
4. Highlight blockers and suggested corrections.

## Output

- A visual plan review artifact with gap and risk annotations.
