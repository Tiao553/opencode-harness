# Generate Slides Command

## Process

1. Read the source material and identify the narrative arc.
2. Split the material into slide-sized sections.
3. Keep each section focused on one point, with supporting detail kept minimal.
4. Use a consistent visual structure so the deck reads coherently.

## Output

- A slide-like artifact suitable for presenting a recap, proposal, or technical summary.
