# Diff Review Command

## Process

1. Read the compared inputs or code changes.
2. Identify the most meaningful deltas instead of rendering a raw dump.
3. Present before and after states side by side where possible.
4. Annotate the changes with findings, risks, or review notes.

## Output

- A visual review artifact that highlights meaningful changes and their implications.
