# Fact Check Command

## Process

1. Read the source material being checked.
2. Separate claims into confirmed, uncertain, and unsupported categories.
3. Present evidence next to each important claim.
4. Keep unsupported claims visible rather than smoothing them over.

## Output

- A visual fact-check artifact with evidence-backed classifications.
