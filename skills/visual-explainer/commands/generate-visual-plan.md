# Generate Visual Plan Command

## Process

1. Read the requested plan context and supporting files.
2. Convert the plan into sections, phases, dependencies, and milestones.
3. Present the sequence visually so order and ownership are obvious.
4. Keep the output concise enough to scan quickly.

## Output

- A standalone visual plan artifact with phases, dependencies, and key actions.
