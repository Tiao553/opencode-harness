## Decisões Chave Preservadas

| Decisão | Escolha |
|---------|---------|
| Nº de DAGs ativos | 3 (bronze, silver, monitor) — não 1 por pipeline |
| Bronze → Silver trigger | Airflow Dataset (`dataset://medallion/bronze/complete`) |
| Concorrência | Pools `pool_bronze` e `pool_silver` com 4 slots cada |
| Dependências entre pipelines | `depends_on` no YAML → TaskGroup chaining |
| Parse-time performance | `LazyProviderOperator` + `.airflowignore` |
| Ingestão Bronze | Cloud Run Job `ingestao` (não GKE/Dataflow provider direto) |

## Lessons Learned

### O que funcionou bem

1. **3 DAGs > N DAGs** — consolidar em 3 DAGs ativos reduziu drasticamente a carga do scheduler e da UI do Composer. A granularidade de pipeline é preservada via TaskGroups sem o custo de múltiplos DAGs.

2. **LazyProviderOperator** — providers do Google causavam timeout de parse (>120s) no Composer. Adiar imports para o momento de execução da task resolveu o problema sem mudar a lógica de negócio.

3. **Dataset scheduling** — usar `Dataset` do Airflow para Bronze → Silver eliminou a necessidade de sensores (`ExternalTaskSensor`) ou `TriggerDagRunOperator`, simplificando o grafo de dependências.

4. **`.airflowignore`** — essencial para performance. Sem ele, o Composer tenta parsear todos os módulos internos como DAG files.

5. **Compatibility stubs** — manter arquivos antigos como stubs não-registradores evitou erros de import durante o rollout no Composer sem exigir limpeza imediata do bucket.

### O que foi difícil

1. **Timeout de parse no Composer** — o problema de parse-time com Google providers não estava documentado claramente. Levou iterações para identificar que a causa era o import de providers no topo dos módulos, não a lógica das factories.

2. **Ausência de `.pre-commit-config.yaml`** — gate de pre-commit não pôde ser validado automaticamente. Recomenda-se adicionar no próximo ciclo.

3. **`schedule` no YAML** — campo `schedule` existia nos YAMLs de config mas não era mais usado após a consolidação. Remoção explícita evitou confusão futura.
